# README 视觉素材

`hero-canvas.jpg` 与 `studio-canvas.jpg` 是 2026-11 为首页新生成的 AI 示意插画：前者用悬浮画板、选框与光标表现「AI 起稿、人来定稿」，后者用图层、画板、选择框与属性面板表现 Studio 画布。两图均不含产品截图、界面文字或第三方照片，仅作概念示意，按 MIT 使用；生成后已裁去水印边。

既有 `hero.svg` 为旧版原创编译工作台插画，保留其引用兼容，MIT。

`qiyu-*.png` 是「栖羽」观鸟原型的编译预览，演示 9 页移动端原型的实际布局。它们展示已生成的原生工程；照片识别、路线和统计为演示数据。26 项浏览器交互断言在本机实际 Axure 预览通过；圆角修复后的复验见 [反馈复验](../../docs/history/trial-reports-2026-10.md#2026-10-25-视觉创作反馈复验)。预览不作为生成耗时、通用质量或第三方服务可用性的证明。
